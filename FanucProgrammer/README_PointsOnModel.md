# Точки по модели (PointsOnModelWindow)

> Общая архитектура проекта: [README.md](../../README.md)

Окно **«Точки по модели»** — модуль Fanuc Programmer для подготовки траекторий робота: загрузка 3D-моделей, SVG, текста и каллиграфии на лист A4, размещение объектов на нумерованной сетке и экспорт управляющей программы (УП) для Fanuc.

## Запуск

Меню главного окна → **Открыть окно «Точки по модели»**.

## Основные возможности

| Раздел | Описание |
|--------|----------|
| **3D модель (FBX)** | Загрузка mesh-модели, создание точек по вершинам, смещение последней модели |
| **SVG / каллиграфия** | Импорт контуров, шаг дискретизации, масштаб, поворот, режимы каллиграфии |
| **Текстовые точки** | Импорт из окна «Текст в точки», параметры шага и инверсии |
| **Лист A4 и сетка** | Рабочая поверхность 210×290 мм, сетка 7×10 ячеек с номерами |
| **Объекты сцены** | Единый список объектов (модель, SVG, текст, каллиграфия) с редактированием |
| **Экспорт УП** | Генерация файла `.ls` с точками `P[n]` для робота Fanuc |

## Управление камерой

- **ЛКМ + перетаскивание** — панорамирование
- **ПКМ + перетаскивание** — вращение
- **Колёсико мыши** — масштаб
- **W/A/S/D** — смещение камеры
- **Стрелки** — поворот (синхронно со слайдерами)
- **Двойной клик** по объекту — панель редактирования

## Архитектура трансформаций

Все координаты проходят через **единый конвейер**, чтобы отображение и экспорт УП совпадали:

```
Локальные точки объекта
  → масштаб → поворот → [инверсия Y сетки] → смещение
  → трансформация листа → [независимая трансформация сетки]
  → коррекция осей (−90° по Z)
  → мировые координаты / координаты робота
```

### Ключевые методы

| Метод | Назначение |
|-------|------------|
| `BuildObjectTransformGroup` | Полная трансформация объекта для 3D-отображения |
| `ApplyObjectTransformation` | Та же цепочка для экспорта точек в УП |
| `TransformSheetLocalPoint` | Лист, сетка, подписи ячеек |
| `WorldToSheetLocal` | Обратное преобразование (выбор ячейки по клику) |

### Важно

- При **«Привязать сетку к листу»** трансформация листа применяется **один раз** (раньше дублировалась и сдвигала объекты).
- **Инверсия сетки** — отражение по Y в локальных координатах листа; не перезаписывает `OffsetX/Y` объектов.
- Объекты на сетке хранят позицию в **локальных координатах листа** (`LocalCenter` ячейки), не в мировых.

## Рабочий процесс

### 1. Подготовка листа

1. При необходимости включите **разметку листа** и **сетку с номерами** (панель редактирования объекта или двойной клик).
2. Задайте смещение/поворот/масштаб листа → **Применить к листу**.
3. **Инверсировать сетку** — если нужна нумерация сверху вниз.

### 2. Добавление объектов

- **FBX** — «Загрузить модель», затем «Создать точки по модели».
- **SVG** — «Load SVG», настройте параметры → «Применить параметры SVG».
- **Текст** — из окна «Текст в точки»; при активной сетке текст автоматически попадает в свободную ячейку.

### 3. Размещение на сетке

1. Двойной клик по объекту → панель редактирования.
2. Включите **«Показать сетку с номерами»**.
3. Введите номер ячейки (1–70) → **Привязать**.
4. Или **«Автопривязка всех объектов»** — по порядку в свободные ячейки.

### 4. Экспорт УП

1. Заполните имя программы, скорость, тип движения (CNT/FINE).
2. **Создать УП** → сохранить `.ls`.

Экспортируются видимые объекты типа **SVG** и **Calligraphy** с учётом всех трансформаций и параметра R (ширина штриха).

## Типы объектов (`SceneObjectType`)

- `Model3D` — FBX-модель (визуализация; точки модели — отдельно через `modelPointsGroup`)
- `SVG` — контур из SVG
- `Calligraphy` — штрихи с подъёмами кисти
- `Text` — точки из текстового генератора

## Параметры листа A4 (константы)

| Параметр | Значение |
|----------|----------|
| Ширина | 210 мм |
| Высота | 290 мм |
| X | −25 … 185 мм |
| Y | −140 … 150 мм |
| Сетка | 7×10 ячеек (30×29 мм) |

## Устранение неполадок

| Проблема | Решение |
|----------|---------|
| Объекты «улетают» после трансформации листа | Убедитесь, что используется актуальная версия с единым конвейером трансформаций |
| Не работает зум колёсиком | Событие `MouseWheel` обрабатывается на области 3D-viewport, не блокируется окном |
| Ячейка не определяется по клику | Включите нумерованную сетку; координаты переводятся через `WorldToSheetLocal` |
| FBX не загружается | Конвертируйте кривые в mesh в Blender/3ds Max, экспортируйте FBX Binary 7.4 |
| Пустой экспорт УП | Добавьте SVG/каллиграфию как объекты сцены (не только legacy-отображение в `svgPointsGroup`) |

## Связанные файлы

- `PointsOnModelWindow.xaml` — интерфейс
- `PointsOnModelWindow.xaml.cs` — логика сцены, трансформаций, экспорта
- `TextToPointsWindow.xaml.cs` — передача текстовых точек в это окно
- `SvgCalligraphyProcessor`, `SvgToRobotPath` — разбор SVG
